# أداة إعداد أخبار الكلية

أداة محلية لصياغة أخبار كلية إدارة الأعمال بحوطة بني تميم (جامعة الأمير سطام بن عبدالعزيز) بالعربية والإنجليزية، مع توليد النص البديل للصور وتصدير ملفات Word، وفق دليل الهوية البصرية للجامعة.

## المتطلبات

- Node.js 20 أو أحدث (مثبت حاليًا: v26).
- أحد الخيارين:
  - **GitHub Copilot** (الافتراضي): حساب GitHub مسجّل الدخول على الجهاز (`gh auth login`) لديه اشتراك Copilot ولو مجانيًا. لا يحتاج أي مفتاح.
  - **Claude**: مفتاح Anthropic API من `console.anthropic.com`.

## التشغيل لأول مرة

1. افتح Terminal داخل مجلد الأداة وثبّت الحزم (مرة واحدة):

   ```bash
   npm install
   ```

2. شغّل الأداة:

   ```bash
   npm start
   ```

3. افتح المتصفح على: <http://localhost:3210>
4. من شريط الإعداد أعلى الصفحة اختر **استخدام GitHub Copilot** (أو الصق مفتاح Claude). يُحفظ الاختيار في `.env` تلقائيًا.

## تغيير المزوّد لاحقًا

اضغط "تغيير" بجانب "المزوّد الحالي" أعلى الصفحة، أو عدّل `AI_PROVIDER` في ملف `.env`.

## المراحل

1. **معلومات الخبر** — ملخص حر أو حقول تفصيلية (لا يشترط تعبئة الكل).
2. **الصور** — رفع/معاينة/استبدال/حذف، وتوليد النص البديل (Alt Text) بالعربية والإنجليزية مع إمكانية التعديل.
3. **توليد الخبر** — نسخة عربية رسمية ونسخة إنجليزية احترافية، مع تنبيه بالمعلومات الناقصة التي لم تُفترض، وإمكانية إعادة التوليد.
4. **المراجعة والتعديل** — النسخة العربية هي الأساس؛ أي تعديل يحدّث الإنجليزية تلقائيًا (أو بزر "تحديث الترجمة الإنجليزية").
5. **الاعتماد والتصدير** — اعتماد الخبر ثم حفظ ملفي Word: `اسم الخبر - AR.docx` و `اسم الخبر - EN.docx` في مجلد تختاره (Chrome/Edge) أو عبر التنزيل.

## إعدادات اختيارية (في `.env`)

- `AI_PROVIDER=copilot` أو `anthropic` — المزوّد.
- `PORT=3210` — منفذ التشغيل.
- `COPILOT_MODEL=auto` — نموذج Copilot.
- `CLAUDE_MODEL=claude-opus-5` — نموذج Claude.

## ملاحظات

- تُحفظ مسودة العمل تلقائيًا في المتصفح (localStorage) حتى الضغط على "خبر جديد" أو "مسح الكل".
- المفتاح يبقى في الخادم المحلي ولا يُرسل إلى المتصفح.
- الخط المستخدم في الواجهة وملفات Word هو Cairo (الخط الإلكتروني المعتمد في دليل الهوية). إن لم يكن مثبتًا على الجهاز الذي يفتح ملف Word فسيستبدله Word تلقائيًا.
